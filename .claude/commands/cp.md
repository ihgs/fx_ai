# /cp

現在の変更をコミットし、リモートに push する。PR 作成は行わない。

## 手順

1. `git-commit` スキルを実行し、変更をコミットする。
   - コミットすべき差分が無ければ、その旨を報告してここで終了する（push は行わない）。
2. `git-push` スキルを実行し、現在のブランチを origin へ push する（必要なら upstream を設定）。

各スキルの内部手順（対象ファイルの選定、コミットメッセージの作法、push 先の確認など）はそれぞれの SKILL.md の定義に従う。ここではその実行順序のみを規定する。

## してはいけないこと
- コミットすべき変更が無いのに push に進むこと
- `gh pr create` など PR 作成に関する操作を行うこと
- 各スキルが定める確認・注意事項（デフォルトブランチへの直接コミット禁止、force push 禁止など）を省略すること
