# AI分析 — Requirements

## Overview
spec 002 で蓄積されたレート履歴を AI で分析し、見通し・示唆を生成する。
定期実行またはユーザーのボタン操作で分析を実行できるようにする。

## User Stories

### 1. 分析の実行
As a ユーザー, I want to レート情報を AI で分析してほしい, So that 自分で判断する手間を減らし、相場の見通しを参考にできる。

- 1.1 WHEN ユーザーが分析画面で「分析実行」ボタンを押した THE SYSTEM SHALL 直近のレート履歴を入力として AI 分析を実行し、結果を表示する。
- 1.2 WHEN 定期実行のタイミングが来た THE SYSTEM SHALL 自動的に AI 分析を実行し、結果を保存する。
- 1.3 WHEN AI 分析の結果が生成された THE SYSTEM SHALL 分析結果（見通し・根拠等）とその実行時刻を DB に保存する。
- 1.4 IF AI 分析の呼び出しに失敗した THEN THE SYSTEM SHALL エラーを表示し、それまでの分析結果一覧はそのまま表示し続ける。
- 1.5 WHEN ユーザーが分析画面を開いた THE SYSTEM SHALL 過去の分析結果一覧（実行時刻・分析内容）を表示する。

## Out of Scope
- 分析結果の正解/不正解判定・正答率算出（→ spec 005）
- 複数の分析手法の切り替えUIや手法ごとの管理（→ spec 005。本specでは分析手法は1つのみ実装する）
- 分析に使う AI モデル・プロンプトの具体的な選定は design.md で決定する
