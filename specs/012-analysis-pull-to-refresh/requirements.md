# 012 分析画面のプル更新 (analysis-pull-to-refresh)

## Overview

分析画面（`AnalysisScreen`）で、スマホの下方向プルジェスチャーにより分析結果一覧・正答率統計を再取得できるようにする。一般的なpull-to-refreshパターン（Twitter/Gmail等）に倣い、一覧が一番上までスクロールされている状態でのみ発動する。更新内容は既存の「分析実行」ボタンとは別物で、AIに新規分析を依頼するのではなく、既存の分析結果一覧・正答率統計を再取得（`GET /api/analysis`の再実行）するだけとする。

## User Stories

### Story 1: 分析結果一覧を下に引っ張って更新する

As a ユーザー,
I want 分析画面を下に引っ張ると最新の分析結果一覧・正答率統計が取得し直される,
So that アプリを再読み込みしなくても最新の状態を確認できる。

- 1.1 WHEN 分析結果一覧が一番上までスクロールされた状態で下方向にドラッグしたとき THE SYSTEM SHALL 引っ張った量に応じたプルインジケーター（矢印/スピナー等）を表示する。
- 1.2 WHEN 一定のしきい値を超えてドラッグした状態で指を離したとき THE SYSTEM SHALL 分析結果一覧・正答率統計を再取得する（既存の`GET /api/analysis`と同じ処理）。
- 1.3 WHEN しきい値未満のドラッグで指を離したとき THE SYSTEM SHALL 更新を行わず表示を元の位置に戻す。
- 1.4 WHILE 再取得処理中 THE SYSTEM SHALL ローディング中であることが分かるインジケーターを表示し続ける。
- 1.5 WHEN 再取得が完了したとき THE SYSTEM SHALL 一覧・正答率統計を最新の内容に差し替え、インジケーターを消す。
- 1.6 IF 再取得に失敗したとき THEN THE SYSTEM SHALL エラーメッセージを表示する（既存のエラー表示に準ずる。一覧自体は直前の表示を維持する）。
- 1.7 IF 一覧が一番上までスクロールされていない状態で下方向にドラッグしたとき THEN THE SYSTEM SHALL 通常のスクロール操作として扱い、プル更新を発動しない。
- 1.8 WHILE AI分析実行中（「分析実行」ボタン押下中）THE SYSTEM SHALL プル操作による再取得を無効化する（同時実行による競合を避ける）。

## Out of Scope

- 分析画面以外の画面（現在レート・ヒストリーチャート・管理画面）へのプル更新導入
- プル操作によるAI分析の新規実行（既存の「分析実行」ボタンのみが新規実行のトリガー）
- PC（マウス操作）でのプル更新相当の操作（対象はスマホのタッチ操作のみ）
- 外部pull-to-refreshライブラリの導入（既存コードの流儀に合わせ、素のタッチイベントで実装する）
