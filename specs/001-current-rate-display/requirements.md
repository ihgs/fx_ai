# 現在レート表示 — Requirements

## Overview
スマートフォンでの閲覧を前提とした Web アプリの最初の機能として、USD/JPY の現在レートを表示する。
アプリ全体の土台（Next.js プロジェクト、モバイル向けレイアウト）もこのspecで整える。

## User Stories

### 1. 現在レートの表示
As a ユーザー, I want to アプリを開いたときに USD/JPY の現在レートを見る, So that 為替レートをすぐ確認できる。

- 1.1 WHEN ユーザーがアプリ（トップ画面）を開いた THE SYSTEM SHALL 現在の USD/JPY レートを取得して表示する。
- 1.2 IF レート取得に失敗した THEN THE SYSTEM SHALL 古い/空のデータの代わりにエラー状態を表示する。
- 1.3 WHEN レート取得中である THE SYSTEM SHALL ローディング状態を表示する。
- 1.4 WHEN レートを表示する THE SYSTEM SHALL そのレートの取得時刻を併記する。

### 2. モバイル最適化
As a スマートフォンユーザー, I want to 画面がスマホサイズに最適化されている, So that 片手でも快適に使える。

- 2.1 WHEN スマートフォン相当の画面幅で表示する THE SYSTEM SHALL 横スクロールが発生せず、文字・タップ領域が読み取り/操作しやすいレイアウトで描画する。
- 2.2 WHEN デバイスの向きが縦（portrait）である THE SYSTEM SHALL 縦向き用に最適化されたレイアウトで描画する。
- 2.3 WHEN デバイスの向きが横（landscape）である THE SYSTEM SHALL 横向き用に最適化されたレイアウトで描画する（縦向きレイアウトの単純な引き伸ばしにしない）。
- 2.4 WHEN デバイスの向きが変化した THE SYSTEM SHALL 表示中のレート情報を保持したままレイアウトのみ切り替える。

### 3. 手動更新
As a ユーザー, I want to 任意のタイミングでレートを更新できる, So that 最新の値を確認したいときに確認できる。

- 3.1 WHEN ユーザーが更新操作（更新ボタン等）を行った THE SYSTEM SHALL レートを再取得して表示を更新する。

## Out of Scope
- レート履歴の DB 保存・チャート表示（→ spec 002）
- 複数画面間のスワイプ切り替え（→ spec 003。本specでは画面は1つのみ）
- AI 分析・正答率（→ spec 004, 005）
- 自動ポーリングによるリアルタイム更新（今回は初回取得＋手動更新のみ。自動更新は将来検討）
