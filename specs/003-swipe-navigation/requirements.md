# 画面スワイプによる切り替え — Requirements

## Overview
現在値画面（spec 001）・チャート画面（spec 002）・分析画面（spec 004 で追加）を、
スワイプ操作で切り替えられるようにする。分析画面が未実装の間はプレースホルダーを表示する。

## User Stories

### 1. スワイプによる画面切り替え
As a ユーザー, I want to 画面を左右にスワイプして切り替える, So that タブやメニューを操作せず直感的に画面を行き来できる。

- 1.1 WHEN ユーザーが左右にスワイプ操作をした THE SYSTEM SHALL 現在値 → チャート → 分析 の順で隣の画面に切り替える。
- 1.2 WHEN いずれかの画面を表示している THE SYSTEM SHALL 現在位置を示すインジケーター（ドット等）を表示する。
- 1.3 IF 分析画面がまだ実装されていない（spec 004 導入前） THEN THE SYSTEM SHALL その位置にプレースホルダー画面（準備中である旨）を表示する。
- 1.4 WHEN スワイプで画面が切り替わった THE SYSTEM SHALL 各画面の状態（チャートの選択期間など）を保持したままにする（切り替えのたびに再取得・リセットしない）。

### 2. スワイプ以外の操作手段
As a ユーザー, I want to スワイプ操作が難しい場合でも画面を切り替えられる, So that 操作性が確保される。

- 2.1 WHEN ユーザーが画面下部のインジケーターをタップした THE SYSTEM SHALL 対応する画面に切り替える。

## Out of Scope
- 分析画面自体の中身（→ spec 004）
- 現在値画面・チャート画面の機能追加（それぞれ spec 001 / 002 の範囲で完結）
- 3画面以外へのページ追加（設定画面など）は将来検討
