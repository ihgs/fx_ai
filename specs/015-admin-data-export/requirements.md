# 015 管理画面のデータダウンロード (admin-data-export)

## Overview

管理画面から、期間を指定して分析データ（正誤判定結果付き）とレートヒストリーデータ（10分間隔）をJSON形式でダウンロードできるようにする。データ検証や振り返りのため、DBの中身をローカルに取り出したいというニーズに対応する。

## User Stories

### Story 1: 期間を指定してデータをダウンロードする

As a 管理者,
I want 管理画面で開始日・終了日を指定してデータをJSONファイルとしてダウンロードしたい,
So that DBの中身をローカルで確認・分析できる。

- 1.1 WHEN 管理画面のダウンロードページで開始日・終了日（JST日付）を指定し実行操作をしたとき THE SYSTEM SHALL 指定期間（開始日の00:00 JSTから終了日の23:59:59 JSTまで、両端含む）のデータをJSONファイルとしてダウンロードする。
- 1.2 THE SYSTEM SHALL ダウンロードするJSONに、指定期間内の分析結果（全method対象、正誤判定結果・判定に使った実レート含む）を含める。
- 1.3 THE SYSTEM SHALL ダウンロードするJSONに、指定期間内のレートヒストリーを10分間隔（毎時0,10,20,30,40,50分）で間引いたデータを含める。
- 1.4 IF 開始日が終了日より後の場合 THEN THE SYSTEM SHALL エラーメッセージを表示しダウンロードを実行しない。
- 1.5 IF 開始日・終了日のいずれかが未入力の場合 THEN THE SYSTEM SHALL 実行操作を無効化する。
- 1.6 WHEN 指定期間内に対象データが1件も無い場合 THEN THE SYSTEM SHALL 各データが空配列のJSONファイルをダウンロードする（エラーにはしない）。
- 1.7 IF データ取得中にサーバーエラーが発生した場合 THEN THE SYSTEM SHALL エラーメッセージを表示する。
- 1.8 IF 指定期間（開始日〜終了日、両端含む）が7日間を超える場合 THEN THE SYSTEM SHALL エラーメッセージを表示しダウンロードを実行しない。

## Out of Scope

- CSV等JSON以外の出力形式
- 認証・アクセス制御（既存の管理画面と同様、追加のログイン機構は設けない）
- 分割ダウンロード（7日を超える期間を複数回に分けて取得する機能）
- ダウンロード履歴の保存
