# 分析結果の答え合わせ・正答率 — Requirements

## Overview
spec 004 で保存された AI 分析結果について、実際のレート推移と照らして後から正解/不正解を判定できるようにし、
正答率を算出する。将来的に分析手法を追加できるよう、拡張可能な設計にする。

## User Stories

### 1. 答え合わせ
As a ユーザー, I want to 過去の分析結果が当たっていたか確認したい, So that AI分析の信頼性を判断できる。

- 1.1 WHEN 分析予測の対象期間が経過した THE SYSTEM SHALL 実際のレート推移と予測を比較し、正解/不正解（またはスコア）を自動判定する。
- 1.2 IF 判定に必要な実績データがまだ揃っていない THEN THE SYSTEM SHALL その分析結果を「判定待ち」として表示する。
- 1.3 WHEN ユーザーが分析結果一覧を見た THE SYSTEM SHALL 各結果に正解/不正解/判定待ちのステータスを表示する。

### 2. 正答率の表示
As a ユーザー, I want to AI分析の正答率を知りたい, So that どの程度信頼できるか把握できる。

- 2.1 WHEN ユーザーが分析画面を開いた THE SYSTEM SHALL 判定済みの分析結果に基づく正答率を表示する。
- 2.2 WHEN 分析手法が複数存在する THE SYSTEM SHALL 分析手法ごとの正答率を分けて表示する。

### 3. 分析手法の拡張性
As a 開発者, I want to 新しい分析手法を追加できる, So that 正答率が低い手法を改善・置き換えできる。

- 3.1 WHEN 新しい分析手法を追加する THE SYSTEM SHALL 既存の分析結果・正答率データに影響を与えずに追加できる（分析手法IDで結果を区別する等）。
- 3.2 WHEN 分析結果を保存する THE SYSTEM SHALL どの分析手法によるものかを記録する。

## Out of Scope
- 具体的な新しい分析手法そのものの実装（正答率を見て都度、別途specを切って追加する）
