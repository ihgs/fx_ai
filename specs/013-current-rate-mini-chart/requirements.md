# 013 現在レート画面のミニチャート (current-rate-mini-chart)

## Overview

現在レート画面（`CurrentRateScreen`）に、直近30分間のレート推移を示すシンプルな線グラフを追加する。軸目盛り・軸ラベル・凡例などのラベル類は表示せず、線のみのシンプルな表示とする。画面が縦向き（portrait）のときは現在レート表示の下に、横向き（landscape）のときは現在レート表示の横に配置する。

## User Stories

### Story 1: 直近30分のレート推移を見る

As a ユーザー,
I want 現在レート画面で直近30分間のレート推移をひと目で確認したい,
So that 現在値だけでなく直近の値動きの傾向も把握できる。

- 1.1 WHEN 現在レート画面を開いたとき THE SYSTEM SHALL 直近30分間のレート推移を線グラフで表示する。
- 1.2 THE SYSTEM SHALL グラフに軸目盛り・軸ラベル・凡例等のラベル類を表示しない（線のみのシンプルな表示とする）。
- 1.3 WHEN 画面が縦向き（portrait）のとき THE SYSTEM SHALL グラフを現在レート表示の下に配置する。
- 1.4 WHEN 画面が横向き（landscape）のとき THE SYSTEM SHALL グラフを現在レート表示の横に配置する。
- 1.5 WHILE 現在レートが自動更新（既存の60秒ポーリング）されている間 THE SYSTEM SHALL グラフのデータも合わせて最新化する。
- 1.6 IF 直近30分間のレートデータが1件も存在しない場合（起動直後等）THEN THE SYSTEM SHALL グラフ領域に簡潔な空状態を示す。
- 1.7 IF グラフデータの取得に失敗したとき THEN THE SYSTEM SHALL 現在レート自体の表示には影響を与えず、グラフ領域のみ空状態として扱う。

## Out of Scope

- グラフのタップ/ホバーによる詳細値表示（ツールチップ）
- 30分以外の期間切り替え（既存のヒストリー画面の役割とは分離する）
- 縦向き・横向き以外のレイアウトバリエーション
- グラフの拡大・スクロール等のインタラクション
