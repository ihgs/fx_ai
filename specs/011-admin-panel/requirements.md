# 011 管理画面 (admin-panel)

## Overview

運用者がPCから直接URLを打って開く管理画面を追加する。アプリ本体（一般利用者向け画面）からのナビゲーションリンクや認証は設けず、`/admin`のURLを知っている人だけがアクセスする想定。`/admin`にトップページを置き、そこから「AI分析結果の一覧・削除」（`/admin/analysis`）と「レートのヒストリーデータを週単位の表で見る」（`/admin/history`）の各機能へリンクで遷移できるようにする。スマホでの利用は考慮しない。

## User Stories

### Story 1: AI分析結果の一覧を見る

As an 運用者,
I want AI分析結果を一覧で確認したい,
So that 過去にどんな分析・予測が行われたかを把握できる。

- 1.1 WHEN 管理画面の分析一覧ページを開いたとき THE SYSTEM SHALL 分析結果を実行日時の新しい順に一覧表示する（実行日時・手法・方向・根拠・対象日時・トリガー種別・正誤判定を含む）。
- 1.2 WHEN 分析結果の件数が1ページの表示上限を超えるとき THE SYSTEM SHALL ページ送り（もしくは「もっと見る」）で残りの結果を閲覧できるようにする。
- 1.3 WHEN 分析結果が1件も存在しないとき THE SYSTEM SHALL 「分析結果がありません」等の空状態を表示する。
- 1.4 WHEN 日時を表示するとき THE SYSTEM SHALL JST（日本時間）で表示する。

### Story 2: AI分析結果を削除する

As an 運用者,
I want 不要・誤った分析結果を削除したい,
So that 一覧やAI分析の的中率統計から除外できる。

- 2.1 WHEN 一覧の各行にある削除操作を実行したとき THE SYSTEM SHALL 削除前に確認ダイアログを表示する。
- 2.2 WHEN 確認ダイアログで削除を確定したとき THE SYSTEM SHALL 該当の分析結果をDBから削除し、一覧から即座に取り除く。
- 2.3 IF 削除対象がAPI呼び出し時点で既に存在しない（他操作で削除済み等）THEN THE SYSTEM SHALL エラーメッセージを表示し、一覧を最新状態に更新する。
- 2.4 削除は1件ずつのみサポートする（複数選択の一括削除は本スコープ外）。

### Story 3: ヒストリーデータを週単位の表で見る

As an 運用者,
I want レートのヒストリーデータを1週間分、時刻×曜日の表形式で見たい,
So that 1週間のレート推移パターンを俯瞰できる。

- 3.1 WHEN 管理画面のヒストリー表ページを開いたとき THE SYSTEM SHALL 直近の週（後述の週定義）のレート表をデフォルト表示する。
- 3.2 THE SYSTEM SHALL 表の列を月曜〜金曜の5列とし、各列はその曜日のセッション（現地JSTで月曜6:30始まり〜翌日5:30終わり、金曜列のみ土曜5:30終わり）を表す。
- 3.3 THE SYSTEM SHALL 表の行を6:30始まりで30分刻みに並べ、翌日5:30まで（各列共通のセッション内時刻オフセット、46スロット・47行）を表示する。
- 3.4 WHEN 該当する30分バケットにレートデータが存在するとき THE SYSTEM SHALL そのバケット終値（bid）をセルに表示する。
- 3.5 IF 該当バケットにレートデータが存在しない（土日クローズ・欠測等）THEN THE SYSTEM SHALL 空欄またはダッシュ（—）をセルに表示する。
- 3.6 WHEN 「前週」「次週」を操作したとき THE SYSTEM SHALL 表示対象の週を1週間分前後に切り替え、その週のデータで表を再描画する。
- 3.7 THE SYSTEM SHALL 表示中の週が「何月何日週」か分かるヘッダーを表示する。
- 3.8 IF データを保持している最古の週より前、または未来の週に移動しようとした場合 THEN THE SYSTEM SHALL 「次週」または「前週」操作を無効化する、もしくは空の表を表示する（実装時にどちらか選択）。

### Story 4: 管理画面のトップページから各機能に遷移する

As an 運用者,
I want `/admin`を開けば他の管理機能へのリンクが並んでいてほしい,
So that 各機能のURLを個別に覚えなくても`/admin`だけ直打ちすればよい。

- 4.1 WHEN `/admin`を開いたとき THE SYSTEM SHALL 「AI分析結果一覧」（`/admin/analysis`）と「レートヒストリー（週次表）」（`/admin/history`）へのリンクを表示する。
- 4.2 WHEN トップページのリンクをクリックしたとき THE SYSTEM SHALL 対応する管理機能のページに遷移する。

## Out of Scope

- 認証・アクセス制御（`/admin`のURL直打ちのみで保護は行わない）
- アプリ本体（一般利用者向け画面）から`/admin`への導線（リンク・メニュー等）の追加
- スマホ・タブロー向けレイアウト対応
- 分析結果の複数選択一括削除・編集
- ヒストリー表のCSVエクスポート等の追加操作
- 週の任意日付ジャンプ（前週/次週の1週送りのみ対応）
- レートデータ自体の手動編集・削除
